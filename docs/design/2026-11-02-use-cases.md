# Home Planner use cases

2026-11-02. The use cases as I see them, numbered and grouped by actor and area, one line each, with where each lives in the code. Lines marked **not built** are ones I believe should exist and could not find; **partial** means some of it exists (the note in the Where column says what). Companion to [2026-11-02-storyboard.md](2026-11-02-storyboard.md).

Actors: a **member** is either person in the household; the **owner** is the household's owner, the DSM admin and whoever deploys it; a **guest** is a friend on the household's list who books a stay through `/book`. 140 use cases: 104 built, 8 partial, 28 not built.

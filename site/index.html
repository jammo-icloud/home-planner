    Start the household's budget

      A budget is a set of envelopes. Each holds a month's money for one thing and the receipts it pays. Together they add up to the income, no more and no less.

      Where to get one
      • Sign in to your bank or card's website and download the account's activity. Prefer QFX or OFX where it is offered: it carries the bank's own id for each transaction, and often every account in one file.
      • CSV works too, as long as its first row names the columns: a date, a payee or description, and an amount.
      • Import a card and the checking account that pays it together, so the payment cancels out.
